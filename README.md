About

BHHF BANNER PRO is a terminal customization tool designed to transform your default terminal interface into a personalized cyber-style environment.

It includes a custom welcome screen, system information display, color themes, operator name customization, terminal prompt styling, and a built-in file listing command.

Features

- Custom BHHF Banner
- 10 selectable terminal themes
- Personalized operator name
- System information display
- Username and hostname detection
- Date and time display
- Random motivational quotes
- Animated loading progress bar
- Custom Bash prompte
- Automatic startup configuration
- Installation & uninstallation options

Supported Platforms

- Termux (Android)
- Linux-based systems using Bash

# Installation

Clone the repository:

git clone https://github.com/darkleocyber/BHHF_BANNER.git

Enter the project directory:

cd BHHF_BANNER

Run the installer:

python Iloveyou.py

---
# Usage

After launching the script, select an option from the menu.

- [1] Install NEXUS PRO
- [2] Uninstall NEXUS PRO
- [0] Exit
---
Choose your preferred theme and enter your operator name to customize your terminal.

After installation, activate Tconfiguration:

- # source ~/.bashrc
